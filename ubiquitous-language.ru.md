## Термины предметной области

- **Граница фермы / Farm Boundary:** физическая и локальная операционная граница одной фермы. Включает Агент фермы, а также физические Устройства и камеры фермы.
- **Граница Центральной платформы / Central Platform Boundary:** центральная граница развёртывания, включающая Центральную платформу, Центральное хранилище данных, Центральное хранилище операций и Центральное S3 (MinIO). Существующий Kafka остаётся внешней общей инфраструктурой для Опубликованных метрик. Выделенный Kafka является отдельной облачной инфраструктурой для синхронизации ферм.
- **MVP-система свиноферм / Pig Farm System MVP:** общая MVP-система. Она включает Центральную платформу и Агентов фермы. Граница Центральной платформы предусматривает бесшовное развитие MVP в SaaS-платформу без связанности будущих SaaS-клиентов с текущим IoT-шлюзом компании.
- **Оператор / Operator:** сотрудник, который работает с Центральной платформой и анализирует События фермы нескольких ферм.
- **Дежурный сотрудник фермы / Farm Duty Employee:** сотрудник, который находится на ферме, получает Локальные уведомления и реагирует на проблемы фермы. Эта роль отличается от роли Оператора, хотя один человек может выполнять обе роли.
- **Выделенный Kafka / Dedicated Kafka (Очередь синхронизации):** отдельный облачный брокер для асинхронной синхронизации данных между Агентами фермы и Центральным сервисом синхронизации. Хранит горячую историю около 30 дней; более старые сообщения выгружаются в Существующее S3-озеро данных не реже одного раза в месяц.
- **Корм / Feed:** ресурс фермы для животных. Система контролирует его запас и прогнозирует расход.
- **Центральная платформа / Central Platform:** центральное приложение, которое принимает данные, синхронизированные фермами, предоставляет функции Оператору и интегрируется с системами головного офиса.
    - **Управление данными Центральной платформы / Central Platform Data Management:** ограниченный контекст, который управляет жизненным циклом синхронизированных Доменных фактов ферм, текущим состоянием и историей, а также их дочерними Артефактами данных.
    - **Аутентификация / Authentication:** компонент Центральной платформы, который аутентифицирует зарегистрированных сотрудников.
    - **Авторизация (RBAC) / Authorization (RBAC):** компонент Центральной платформы, который авторизует доступ к центральным функциям по роли.
    - **Центральный сервис синхронизации / Central Synchronization Service:** компонент Синхронизации ферм, который принимает и валидирует входящие данные. Сохранение и жизненный цикл данных принадлежат Управлению данными Центральной платформы.
    - **Центральное веб-приложение фермы / Central Farm Web Application:** компонент Центральной платформы, который предоставляет Оператору пользовательский интерфейс для нескольких ферм.
    - **Центральное хранилище данных / Central Data Store:** PostgreSQL-хранилище, принадлежащее Управлению данными Центральной платформы. Хранит синхронизированные Доменные факты, текущее состояние ферм, историю Доменных фактов, ссылки на дочерние Артефакты данных и их метаданные.
    - **Центральное хранилище операций / Central Operations Store:** PostgreSQL-хранилище, принадлежащее Центральным операциям. Хранит операторские представления данных, результаты межферменного анализа, состояние уведомлений Оператора, назначенные локальные реакции, статусы их координации и журнал операционных действий.
    - **Центральное S3-хранилище (MinIO) / Central S3 (MinIO):** C4-контейнер хранения Артефактов данных Центральной платформы.
    - **Запасы и прогноз корма / Feed Inventory and Forecast:** компонент Центральной платформы, который принимает синхронизированные данные о текущем запасе и потреблении корма от Агентов фермы. Он формирует межферменные прогнозы потребления и отклонений.
    - **Настройка метрик / Metric Configuration:** компонент Центральной платформы, который поддерживает настройку базовых и пользовательских операционных метрик фермы.
    - **Публикатор метрик / Metrics Publisher:** компонент Центральной платформы, который публикует Опубликованные метрики через Существующий Kafka.
    - **Сервис архивирования / Archiver Service:** компонент Центральной платформы, который читает холодные записи синхронизации из Выделенного Kafka, формирует архивные объекты и сохраняет их в Существующем S3-озере данных.
    - **Опубликованная метрика / Published Metric:** именованное измерение, сформированное из телеметрии или событий фермы и доступное другим системам.
- **Агент фермы / Farm Agent (агент):** локальный программно-аппаратный узел одной фермы. Он продолжает работать при отсутствии интернет-соединения.
    - **Локальный шлюз устройств / Local Device Gateway:** компонент Агента фермы, который интегрируется с устройствами фермы, собирает их телеметрию и отправляет команды управления.
    - **Интеграция с камерами / Camera Integration:** компонент Агента фермы, который принимает видеопотоки от камер разных производителей.
    - **Видеоаналитика / Video Analytics:** компонент Агента фермы, который выполняет анализ видеопотоков в реальном времени.
    - **Обнаружение инцидентов с животными / Livestock Incident Detection:** компонент Агента фермы, который создаёт События фермы для обнаруженных инцидентов состояния и поведения животных.
    - **Подсчёт поголовья / Livestock Counting:** компонент Агента фермы, который рассчитывает количество поголовья на основе результатов аналитики.
    - **Локальный буфер / Local Buffer:** компонент Управления данными фермы, который координирует буферизацию и подготовку локально сохранённых данных к синхронизации.
    - **Локальное хранилище / Local Storage:** база данных Управления данными фермы, которая надёжно хранит телеметрию, События фермы, связанные значения и состояние синхронизации при отсутствии связи на ферме.
    - **Локальное S3-хранилище (MinIO) / Local S3 (MinIO):** C4-контейнер хранения Артефактов данных фермы при отсутствии связи на ферме.
    - **Локальный сервис синхронизации / Local Synchronization Service:** компонент Агента фермы, который читает локально сохранённые данные, публикует их через выбранный надёжный транспорт синхронизации и отслеживает доставку после восстановления связи.
    - **Событие фермы / Farm Event:** событие с меткой времени, которое Агент фермы сообщает, например, об обнаруженном инциденте или изменении состояния устройства.
    - **Локальное уведомление / Local Notification:** уведомление, которое Агент фермы отправляет Дежурному сотруднику фермы.
- **Существующий IoT-шлюз / Existing IoT Gateway (IoT шлюз):** текущий центральный IoT-шлюз компании. Он отличается от Локального шлюза устройств Агента фермы.
- **Существующий Kafka / Existing Kafka (Брокер сообщений):** текущий центральный брокер сообщений компании для асинхронной корпоративной интеграции.
- **Существующий веб-портал / Existing Web Portal (Веб-портал):** текущий веб-портал на React для общих функций управления фермой директора хозяйства.
- **Существующее S3-озеро данных / Existing S3 Data Lake (Data Lake):** текущее офисное S3-совместимое озеро данных компании. Оно хранит архивы холодной истории синхронизации, созданные Сервисом архивирования.
- **Доменный факт / Domain Fact:** бизнес-факт, состояние или значение предметной области, которое система создаёт, сохраняет или передаёт. Артефакты данных являются дочерними элементами Доменного факта и не входят в него неявно.
- **Артефакты данных / Data Artefacts:** дочерние элементы Доменного факта, которые содержат видео, аудио, изображения, документы или другие бинарные и структурированные данные.
- **Системное сообщение / Application Event:** сообщение, которым приложение сообщает другому компоненту о Доменном факте или изменении состояния. Это транспортное представление, а не отдельный бизнес-факт.

## Ограниченные контексты / Bounded Contexts

- **Мониторинг и обнаружение инцидентов на ферме / Livestock Monitoring and Incident Detection:** обнаруживает инциденты поведения и состояния животных, выполняет видеоаналитику и подсчёт поголовья, создаёт Доменные факты.
- **Управление устройствами и локальное реагирование / Device Operations and Local Response:** интегрирует устройства фермы, собирает их данные, передаёт команды управления и отправляет Локальные уведомления.
- **Управление данными фермы / Farm Data Management:** управляет жизненным циклом локальных Доменных фактов и их Артефактов данных, сохраняет их при отсутствии связи и подготавливает к синхронизации.
- **Центральные операции / Central Operations:** предоставляет Оператору межферменное представление и анализ Доменных фактов и координирует устранение проблем.
- **Управление доступом / Access Management:** аутентифицирует сотрудников и авторизует доступ к функциям Центральной платформы по ролям.
- **Публикация метрик / Metrics Publication:** формирует и публикует Опубликованные метрики для внешних потребителей.
- **Запасы и прогноз корма / Feed Inventory and Forecast:** принимает данные о запасах и потреблении корма и формирует межферменные прогнозы.
- **Управление данными Центральной платформы / Central Platform Data Management:** управляет жизненным циклом синхронизированных Доменных фактов и их дочерних Артефактов данных.
- **Синхронизация ферм / Farm Synchronization:** определяет протокол и правила доставки Доменных фактов и их Артефактов данных между Агентами фермы и Центральной платформой; не владеет их жизненным циклом.
