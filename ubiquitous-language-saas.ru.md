## Термины предметной области

### SaaS platform and boundaries

- **SaaS-платформа / SaaS Platform:** мультитенантная облачная платформа, которая объединяет Плоскость управления SaaS и Центральные платформы (тенантов).
- **Плоскость управления SaaS / SaaS Control Plane:** коммерческая часть мультитенантной SaaS-платформы, которая управляет жизненным циклом тенанта, идентификацией, правами доступа, подписками, биллингом, провижинингом, метриками использования, квотами и API тенанта.
- **Центральная платформа (тенанта) / (Tenant) Central Platform:** платформа тенанта, которая управляет структурами ферм, мониторингом, событиями и разрешёнными действиями; для первого тенанта эту роль выполняют Центральная платформа и Агенты MVP-системы.
- **Клиент SaaS-платформы / SaaS Client:** организация, которая использует SaaS-платформу на основании договора или активной подписки; текущая компания является первым клиентом SaaS-платформы.
- **Тенант / Tenant:** изолированный контекст, включающий пользователей, фермы, настройки и данные.
- **Изоляция тенанта / Tenant Isolation:** правило, которое предотвращает доступ одного тенанта к пользователям, фермам, настройкам и данным другого тенанта.

### Customer lifecycle and commercial model

- **Онбординг тенанта / Tenant Onboarding (Customer Onboarding):** процесс регистрации тенанта, создания его изолированных ресурсов, провижининга его ферм и пользователей и активации доступа к SaaS-платформе.
- **Метрика использования / Usage Metric:** данные об активности тенанта и потреблении ресурсов в пределах тенанта, собираемые для аналитики и биллинга.
- **Право доступа / Entitlement:** функция или лимит SaaS-платформы, доступные тенанту согласно его тарифу и подписке.
- **Российская платёжная система / Russian Payment System:** внешняя платёжная система, которая обрабатывает платежи за подписки SaaS-платформы.
- **Каталог тарифов / Tariff Catalog (компонент):** компонент, который определяет тарифные планы и лимиты SaaS-платформы.
- **Жизненный цикл подписки / Subscription Lifecycle (компонент):** компонент, который управляет активацией, изменением, приостановкой и отменой подписки тенанта.
- **Расчёт Права доступа / Entitlement Calculation (компонент):** компонент, который определяет доступные тенанту функции и лимиты согласно тарифу и подписке.
- **Сбор Метрик использования / Usage Metric Collection (компонент):** компонент, который регистрирует активность тенанта как Метрики использования.
- **Агрегация Метрик использования / Usage Metric Aggregation (компонент):** компонент, который формирует аналитические и биллинговые данные из Метрик использования.
- **Расчёт начислений / Charge Calculation (компонент):** компонент, который рассчитывает сумму оплаты тенанта на основании тарифа, условий подписки и Метрик использования.
- **Управление счетами / Invoice Management (компонент):** компонент, который создаёт и отслеживает счета тенанта.
- **Адаптер Российской платёжной системы / Russian Payment System Adapter (компонент):** компонент, который передаёт платёжные данные и запросы между SaaS-платформой и Российской платёжной системой.
- **Обработчик результата платежа / Payment Result Handler (компонент):** компонент, который обрабатывает результаты платежей и обратные вызовы от Российской платёжной системы.

### Identity and access

- **Провайдер идентификации / Identity Provider:** внешняя система, которая аутентифицирует пользователей и формирует их утверждения об идентичности и тенанте.
- **Администратор тенанта / Tenant Administrator (Customer Account Administrator):** пользователь тенанта, который управляет тенантом, его пользователями, подпиской и интеграциями.
- **Оператор тенанта / Tenant Operator:** пользователь тенанта, который контролирует данные ферм и координирует Операционные задачи фермы.
- **Интеграция SaaS-платформы и Центральной платформы / SaaS and Central Platform Integration:** интеграция, через которую Центральная платформа (тенанта) запрашивает у SaaS-платформы аутентификацию и авторизацию пользователя. SaaS-платформа передаёт результат проверки Права доступа до предоставления доступа к функциям Центральной платформы (тенанта).

### Customer integrations

- **API тенанта / Tenant API (Customer API):** документированный API SaaS-платформы, через который Информационная система клиента получает разрешённые данные и функции; API является внешней границей доступа к SaaS-платформе, а Существующий Kafka, Выделенный Kafka и хранилища MVP-системы принадлежат внутренней инфраструктуре MVP-системы.
- **Контракт интеграции / Integration Contract:** документированное соглашение о данных, операциях, правах доступа и правилах обмена между SaaS-платформой, Центральной платформой (тенанта) или внешней системой.
- **Информационная система клиента / Customer Information System:** внешняя информационная система, принадлежащая или используемая клиентом SaaS-платформы.

### SaaS provider operations

- **Операционный персонал провайдера SaaS / SaaS Provider Operations Staff:** сотрудники провайдера SaaS-платформы, которые контролируют состояние тенантов и платформенных сервисов.
